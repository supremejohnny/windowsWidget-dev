# Window Pet v0.0.1

首个 Windows 发布版：把挂件挂到打开的窗口上，随窗口移动自然摆动。

## 下载与使用

下载 `WindowPet-0.0.1.exe`，双击启动，无需安装或额外 assets 文件夹。

1. 选择目标窗口和挂件。
2. 选择左上、右上、左下或右下，以及短/中/长/超长绳子。
3. 点击 **Attach**。点击挂件可戳动；点击锚点可收起或展开。
4. 点击 **Detach** 解除挂载；关闭设置窗口退出。

## 功能

- 12 段挂绳，随窗口运动产生摆动和弯曲。
- 挂件从顶部悬挂，按质心产生旋转。
- 收起后保留固定锚点和一小段静态绳子。
- 其他窗口可正常遮挡挂件；透明绘制区域不阻挡点击。
- 内置三款简绘挂件及 `amiya_test1` 测试角色。
- 单 EXE，版本信息与第三方声明内嵌，可在 About 查看。

## 系统与测试

面向 Windows 10/11 普通桌面环境，使用系统 .NET Framework。当前完整验证环境为 Windows 10 22H2 x64；Windows 11、ARM64 和其他系统尚待实测。macOS 版本尚未提供。

用户反馈：约 2.5 小时运行后占用正常、无卡顿。短时独立采样私有工作集约 14 MiB；不同资源统计口径和机器会有差异。

通过物理参考一致性、窗口跟随/遮挡、点击穿透、收起/展开以及无外部资源目录的 32/64 位 CLR 加载测试。

混合 DPI 多屏、虚拟桌面、管理员/置顶目标窗口仍待进一步适配。独占全屏与安全桌面不在当前支持范围。
