# Window Pet 0.0.1-pre

首个 Windows 预览版候选。物理基线已经由用户确认通过。

## 使用

下载 `WindowPet-0.0.1-pre.exe`，双击启动。选一个打开的窗口、挂件、四角位置和绳长，点击 Attach。点击挂件可戳动；点击锚点可收起/展开；关闭设置窗退出。

内置 Lilac cat、Honey bear、Mint ghost 和 amiya_test1；四档绳长为 55/85/130/190 px。图片内嵌，不需外部 assets 文件夹或 Node/开发 SDK。

## 系统与已知边界

- 首版面向普通 Windows 10/11 桌面环境，使用系统 .NET Framework。当前完整实测是 Windows 10 22H2 x64；Windows 11、ARM64 尚未实测。
- AnyCPU EXE 的内嵌图片/声明已分别通过本机 32/64 位 CLR 加载测试；不代表其他 OS/CPU 已完成 GUI 测试。
- 混合 DPI 多屏、虚拟桌面、TopMost/管理员目标窗口、睡眠恢复和远程桌面尚待补齐。
- 其他窗口的遮挡顺序最多有一个静止轮询周期（约 66 ms）的同步延迟。
- 不承诺独占全屏、UAC 安全桌面；当前一次挂载一个窗口，无开机自启或自动恢复配置。
- macOS 只有可行性研究，当前没有 Mac 二进制。

## 占用

用户观察约 14 MB 私有驻留内存。本轮原进程短时安静采样约 13.95 MiB 私有工作集、32.46 MiB 私有提交；GDI/USER 句柄稳定。一小时结果待加入，不能把短时结果标作长时间泄漏验证。

## 构建与验证

```powershell
.\build-release.ps1
```

产物在 `dist/v0.0.1-pre/`：单 EXE、SHA256SUMS.txt、此说明。发布构建不会覆盖项目根目录正在运行的 WindowPet.exe。`test-portable.ps1` 将候选复制到含空格与中文的空目录，验证图片、质量分布、版本、AnyCPU 和内嵌 MIT 声明。`test.ps1` 执行已有物理与窗口行为测试。

2026-10-06 本机验证：

- 候选 EXE 为 1,456,128 bytes（约 1.39 MiB）；SHA-256 见同目录 SHA256SUMS.txt。
- `build-release.ps1` 成功；隔离目录的 x64/x86 CLR 资源测试均通过。
- `test.ps1` 全部通过：450 个上游参考点、四档绳长、挂件角运动、窗口行为与真实窗口移动渲染。
- 300 帧重绘 GDI 句柄 `43 → 43`；本轮真实窗口左右反向移动的绳子最大弯曲约 3.34 px。
- 原进程 PID 30884、启动时间 20:18:54 保持不变，未用候选替换用户的一小时观察进程。

这些结果只来自本机 Windows 10 x64；完整 GUI 未在 x86 OS、Windows 11 或 ARM64 上验证。
