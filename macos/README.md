# Window Pet macOS 动态绳版

本目录是 Swift + AppKit 原生应用，当前采用针对 macOS 窗口采样优化的挂绳模型。Windows 源文件保持原样，旧 Swift 物理适配器作为比较参考保留；当前应用恢复独立绳节点模拟，减少段数以控制高频波浪。构建物在 `dist/macos/Window Pet.app`，目前仅验证 Apple Silicon 本机 喵

## 构建与体验

在开发根目录执行：

```sh
./macos/build.sh
open "dist/macos/Window Pet.app" --args --demo
```

需要 Apple Command Line Tools，无额外 Swift 包、浏览器、Electron 或 .NET。控制面板提供四个角色、四个角落和 55 / 85 / 130 / 190 点绳长。点击“演示窗口”重新应用设置；选择真实应用后点击“挂载”。点击角色戳动，点击锚点收起为 18 点绳头，再次点击展开；关闭控制面板退出 喵

## 当前模型

| 部分 | 实现 |
| --- | --- |
| 固定锚点 | 原生附属窗口或 AX / Window Server 几何跟随，独立于物理刷新 |
| 动态绳子 | `Sources/MacRopePhysics.swift`，6 段 / 7 节点，120 Hz Verlet 步进与长度约束；自由节点各自保留位置和速度 |
| 输入适配 | 锚点局部坐标模拟，80 ms 速度滤波、45 ms 加速度滤波；加速度限幅 1600 点/秒²，以 0.60 增益施加惯性 |
| 质量与阻尼 | 挂件端点质量为单个绳节点的 4 倍；所有自由节点有重力；阻尼按时间缩放，60 Hz 对应 0.955 |
| 长度约束 | 最多 500 次迭代，单段停止容差 0.001 点；当前测试折线总长度误差小于 0.003 点 |
| 绳子绘制 | 平滑插值穿过实际物理节点，保留线色、宽度与高光；没有预设绳形或把上段锁直 |
| 角色旋转 | 从 PNG alpha 测量质心和转动惯量，以顶部支点旋转 |
| 输入与透明度 | 同一个非激活窗口按角色/锚点范围接收点击，其余位置穿透；空白画布 alpha 为 0 |
| 比较参考 | `Sources/Physics.swift` 的 `LegacyRopePhysics` 与 Verlet 核，供测试对照使用 |

上一版用单个挂件端点驱动受限曲线，导致绳子自身动态不足，已撤销。当前取舍是把 Windows 的 12 段降为 6 段，保留独立弯曲与回弹，减少高频振型，并过滤 macOS 窗口几何量化带来的加速度噪声。戳动仅向末端施加冲量，随后通过约束与各节点的惯性改变整根绳子；窗口停止移动后，绳身仍会继续弯曲、反向并逐渐回稳 喵

这是针对 Mac 桌面输入调校的离散绳模型，物理效果不再宣称与 Windows 1:1。段数、质量比和绳身重力已作调整；有效向下重力最低保持 120 点/秒²，节点速度限幅 240 点/秒，因此极端向下拖动的自由落体与松绳折叠仍是有界近似。测试中的长度误差指节点折线，平滑绘制路径的弧长未作同等约束 喵

## 窗口跟随

演示通过 AppKit 子窗口关系同步定位。其他应用使用逐屏幕帧的后台几何采样；已有辅助功能授权且唯一匹配窗口时，通知与采样统一使用同一个 AX 元素。新窗口辅助功能信息尚未就绪时，短时重试最多三次。控制面板显示当前跟随模式；用户可自行通过“辅助功能设置”授权后重新挂载，应用不会修改系统权限 喵

几何立即定位，物理运动期间约 16 ms 刷新、静止约 66 ms 刷新。绘制使用 sRGB 与 Retina 逻辑点。外部窗口不是同一 Window Server 原子移动，仍可能有帧间位置差；普通遮挡已测试，Spaces、Stage Manager、全屏、多屏和长期资源占用仍未完整验证 喵

## 测试与结果

```sh
./macos/test.sh
./macos/test.sh --ui
```

基础测试继续验证旧 Verlet 核的 450 个参考节点。Mac 测试覆盖四档绳长的量化微动、不均匀回调、强拖后继续弯曲、戳动后的双向回弹、回稳、垂直微动、长度约束，以及完整运动轨迹在 60 / 120 / 240 Hz 输入下的一致性。强拖与戳动同时要求最低绳身弯曲量，防止重新退化为静态线或只有挂件摆动 喵

上段指标统一取绳长的上方四分之一，并在节点之间插值采样边界，保证不同段数的比较位置相同。2026-10-07 固定输入本机实测：

| 输入场景 | 6 段动态模型结果 |
| --- | --- |
| 四档绳长、正负 2 点量化输入与不均匀回调 | 上段横向位移 0.50–0.86 点，独立弯曲 0.62–0.86 点；末端位移 0.84–1.28 点 |
| 同一输入的旧 12 段模型 | 上段横向位移 1.72–2.40 点，独立弯曲 1.69–2.02 点 |
| 72 点 / 0.1 秒甩动，随后固定窗口 | 末端最大位移 18.06–24.53 点；停止后的绳身弯曲 4.18–7.46 点，随后回稳 |
| 点击戳动 | 末端最大位移 10.29–15.27 点；绳身弯曲 3.41–6.34 点，产生两个方向的回弹后回稳 |
| 实际独立窗口，横向正负 2 点加纵向正负 1 点 | 85 / 190 点绳长上段位移约 0.96 / 0.76 点；角色旋转约 1 度 |
| 四档实际窗口慢拖 | 绳身弯曲约 0.10–0.28 点 |
| 实际独立窗口明显移动 | 绳身最大弯曲约 5.27 点 |
| 60 / 120 / 240 Hz 相同输入 | 全节点完整轨迹误差小于 0.02 点，当前固定轨迹测得 0 |

窗口测试使用独立应用做实际慢拖、微动和明显移动，另检查四角、事件、层级、透明画布、收起与恢复；测试后自动关闭临时窗口。原始结果在 `.test-output/macos/ui-smoke.txt`，慢拖轨迹在相应 `.slow-<length>.csv`，动态绳预览在 `.dynamic.png`。这些是固定输入与自动窗口移动检查，真实鼠标拖动的手感、不同应用与显示器仍需实际体验确认 喵
