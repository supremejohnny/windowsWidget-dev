# Window Pet macOS 动态绳版

本目录是 Swift + AppKit 原生应用，当前采用针对 macOS 窗口采样优化的挂绳模型。Windows 源文件保持原样，旧 Swift 物理适配器作为比较参考保留；当前应用恢复独立绳节点模拟，减少段数以控制高频波浪。构建物在 `dist/macos/Window Pet.app`，目前仅验证 Apple Silicon 本机 喵

## 构建与体验

在开发根目录执行：

```sh
./macos/build.sh
open "dist/macos/Window Pet.app" --args --demo
```

需要 Apple Command Line Tools，无额外 Swift 包、浏览器、Electron 或 .NET。控制面板提供四个角色、四个角落和 55 / 85 / 130 / 190 点绳长。点击“演示窗口”重新应用设置；选择目标应用后点击“挂载”，再切到要挂载的真实窗口完成绑定。点击角色戳动，点击锚点收起为 18 点绳头，再次点击展开；关闭控制面板退出 喵

## 当前模型

| 部分 | 实现 |
| --- | --- |
| 固定锚点 | 原生附属窗口或 AX / Window Server 几何跟随，独立于物理刷新 |
| 动态绳子 | `Sources/MacRopePhysics.swift`，10 段 / 11 节点，120 Hz Verlet 步进与长度约束；自由节点各自保留位置和速度 |
| 输入适配 | 锚点局部坐标模拟，80 ms 速度滤波、45 ms 加速度滤波；加速度限幅 1600 点/秒²，以 0.60 增益施加惯性 |
| 质量与阻尼 | 节点质量按 6/10 缩放，挂件质量不变；所有自由节点有重力；阻尼按时间缩放，60 Hz 对应 0.955 |
| 长度约束 | 最多 1000 次迭代，单段停止容差 0.0004 点；当前测试折线总长度误差小于 0.002 点 |
| 绳子绘制 | 平滑插值穿过实际物理节点，保留线色、宽度与高光；没有预设绳形或把上段锁直 |
| 角色旋转 | 从 PNG alpha 测量质心和转动惯量，以顶部支点旋转 |
| 输入与透明度 | 同一个非激活窗口按角色/锚点范围接收点击，其余位置穿透；空白画布 alpha 为 0 |
| 比较参考 | `Sources/Physics.swift` 的 `LegacyRopePhysics` 与 Verlet 核，供测试对照使用 |

上一版用单个挂件端点驱动受限曲线，导致绳子自身动态不足，已撤销。用户认可 6 段动态后，当前提高到 10 段并按段数缩放节点质量，保留独立弯曲与回弹，并过滤 macOS 窗口几何量化带来的加速度噪声。戳动仅向末端施加冲量，随后通过约束与各节点的惯性改变整根绳子；窗口停止移动后，绳身仍会继续弯曲、反向并逐渐回稳 喵

这是针对 Mac 桌面输入调校的离散绳模型，物理效果不再宣称与 Windows 1:1。段数、质量比和绳身重力已作调整；有效向下重力最低保持 120 点/秒²，节点速度限幅 240 点/秒，因此极端向下拖动的自由落体与松绳折叠仍是有界近似。测试中的长度误差指节点折线，平滑绘制路径的弧长未作同等约束 喵

## 窗口跟随

演示通过 AppKit 子窗口关系同步定位。其他应用使用逐屏幕帧的后台几何采样；已有辅助功能授权且唯一匹配窗口时，通知与采样统一使用同一个 AX 元素。新窗口辅助功能信息尚未就绪时，短时重试最多三次。控制面板显示当前跟随模式；用户可自行通过“辅助功能设置”授权后重新挂载，应用不会修改系统权限 喵

几何立即定位，物理运动期间约 16 ms 刷新、静止约 66 ms 刷新。绘制使用 sRGB 与 Retina 逻辑点。外部窗口不是同一 Window Server 原子移动，仍可能有帧间位置差；多屏和长期资源占用仍未完整验证 喵

## 台前调度与全屏

底层仍枚举所有桌面的窗口，选择器改为正常桌面应用列表，每个应用只有一个入口，按应用名称排序并按 PID 保留选择。过滤透明内部表面、后台辅助进程与台前调度系统窗口。点击“挂载”后切到该应用想挂的窗口，等待系统切换完成后绑定其当前前台窗口；已有 AX 授权时使用焦点窗口匹配，其他情况使用该应用最前面的可见窗口，无需猜测内部 Window ID。同应用另一个窗口需要重新挂载；“卸下”同时取消待绑定状态，旧异步回调不能重建挂件 喵

挂件使用非激活面板，macOS 13 及以上声明 `canJoinAllApplications`，控制面板声明 `auxiliary`，使挂件可以加入目标应用的台前调度分组与全屏空间。外部挂件在目标前台期间使用非激活浮动层级，只在首次显示或恢复时排到自身层级前面。目标应用在拖动时重新置前普通窗口也不会盖住挂件，物理 tick 与普通拖动不重复排序；后台仍立即隐藏并释放点击。原生演示子窗口维持普通层级 喵

当前采用前台目标策略：切换应用、切换桌面、最小化或同应用另一窗口取得焦点时，隐藏挂件并穿透输入；原目标再次成为前台窗口后自动恢复。切换时暂停物理积分，恢复时保留绳形与角速度，并重新建立身体支点采样，避免系统切换动画产生冲量。恢复需至少 150 ms 的切换缓冲与稳定几何样本；持续移动的恢复最多等待约 300 ms，正常拖动无额外延迟。未授权辅助功能时，以 Window Server 中该应用最前面的可见窗口作为焦点回退，最多 250 ms 更新一次 喵

该实现不使用私有 Spaces API，也不会主动拉回或激活目标窗口。目标关闭后需要重新选择；挂件在后台暂停显示是当前明确的产品行为。独立 AppKit 测试应用位于 `Tests/SwitchingWindow.swift`，已在开启台前调度的本机检查真实应用切换、最小化 / 恢复、全屏进出与多窗口焦点；全屏恢复后同时核对面板位于当前空间且被 Window Server 显示。Codex 侧边缩略图的直接点击仍需用户复核 喵

本次没有修改 `MacRopePhysics.swift`。完整轨迹回归仍使用相同基准和阈值。实际微动测试的上段弯曲量：上一版在相同环境测得 1.016 点，本次两次测得 1.007 / 1.023 点；因此只把实际窗口测试上限从 1.0 放宽到 1.1 点，以容纳异步回调调度波动，生产物理参数不变。原来立即 `orderOut` 的窗口发现测试改为等待 Window Server 创建窗口后最小化，符合可枚举但不在活动桌面的真实情况 喵

## 测试与结果

```sh
./macos/test.sh
./macos/test.sh --ui
```

基础测试继续验证旧 Verlet 核的 450 个参考节点。Mac 测试覆盖四档绳长的量化微动、不均匀回调、强拖后继续弯曲、戳动后的双向回弹、回稳、垂直微动、长度约束，以及完整运动轨迹在 60 / 120 / 240 Hz 输入下的一致性。强拖与戳动同时要求最低绳身弯曲量，防止重新退化为静态线或只有挂件摆动 喵

上段指标统一取绳长的上方四分之一，并在节点之间插值采样边界，保证不同段数的比较位置相同。2026-10-07 固定输入本机实测：

| 输入场景 | 10 段动态模型结果 |
| --- | --- |
| 四档绳长、正负 2 点量化输入与不均匀回调 | 上段横向位移 0.48–0.90 点，独立弯曲 0.63–0.93 点；末端位移 0.83–1.29 点 |
| 同一输入的旧 12 段模型 | 上段横向位移 1.72–2.40 点，独立弯曲 1.69–2.02 点 |
| 72 点 / 0.1 秒甩动，随后固定窗口 | 末端最大位移 17.95–24.45 点；停止后的绳身弯曲 4.24–7.49 点，随后回稳 |
| 点击戳动 | 末端最大位移 9.92–14.69 点；绳身弯曲 3.38–6.17 点，产生两个方向的回弹后回稳 |
| 实际独立窗口慢拖、四档绳长 | 最大弯曲 0.11–0.26 点 |
| 实际独立窗口微动、85 / 190 点绳长 | 上段位移约 0.97 / 0.79 点，末端约 1.13 / 0.87 点 |
| 60 / 120 / 240 Hz 相同输入 | 全节点完整轨迹误差小于 0.02 点，当前固定轨迹测得 0 |

窗口测试使用独立应用做实际慢拖、微动和明显移动，另检查四角、事件、层级、透明画布、收起与恢复；测试后自动关闭临时窗口。最终发布包的独立窗口复核在 `.test-output/macos/release-final-ui.txt`，完整构建测试结果在 `.test-output/macos/release-validation.txt`，初次窗口结果在 `.test-output/macos/ui-smoke.txt`，慢拖轨迹在相应 `.slow-<length>.csv`，动态绳预览在 `.dynamic.png`。这些是固定输入与自动窗口移动检查，真实鼠标拖动的手感、不同应用与显示器仍需实际体验确认 喵

## 基准与无行为变化的优化

`Tests/ApprovedRopePhysics.swift` 冻结用户认可的 6 段版本（开发提交 `935d742`）。生产版以 10 段模拟，阻尼、重力、滤波、120 Hz 步进、戳动力度与睡眠条件保持原参数。段数增加后收紧长度约束容差；20 组完整轨迹比较覆盖四档绳长的微动、慢拖、明显甩动、戳动和斜向移动。末端最大差异：明显甩动 0.209 点，慢拖 0.005 点，微动 0.070 点，戳动 0.598 点；插值后的绳形最大差异 1.078 点，角色角度最大差异 0.003 弧度。这是分辨率变化的小偏差，不宣称轨迹完全相同 喵

独立检查了固定滤波系数预计算、节点输出数组复用与共同惯性力提取的优化，优化前后 158,400 个节点位置和全部休眠决定逐位一致。没有修改窗口跟随、绘制颜色、点击区域或动画时长；未据此宣称 CPU 占用降低了某个百分比 喵
